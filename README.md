# Tic-Tac-Toe-program
A Python- program Tic Tac Toe game featuring two-player gameplay, an interactive 3X3 board, input validation, win/draw detection, and simple game logic.
Overview of the project
Tic Tac Toe is a simple two player game developed by python.The game is played on a 3x3 grid where two player take turns marking their positions with X and O.The player who successful places three of their marks in horizontal, vertical or diagonal row wins the game.
Features
Two-player gameplay
3×3 game board
Player X and Player O
Turn-by-turn gameplay
Automatic winner detection
Draw/tie detection
Invalid input handling
Simple and user-friendly interface
Option to restart/play again

Problem Statement
Traditional Tic Tac Toe requires players to manually draw a board and keep track of their moves. This project aims to develop a simple digital version of the Tic Tac Toe game using Python.
The system allows two players to play the game on a 3×3 board and automatically checks for winning combinations, draw conditions, and invalid moves.
The project focuses on developing a simple and interactive two-player Tic Tac Toe game.
The current project includes:
3×3 game board
Two-player mode
Turn management
Winner detection
Draw detection
Invalid move handling
Game restart functionality
In the future, the project can be extended by adding a computer/AI opponent, graphical user interface (GUI), score tracking, difficulty levels, and multiplayer functionality.Target Users
The target users of this project are:
Students
Beginners learning Python
Casual game players
Teachers for demonstrating programming concepts
Anyone interested in simple computer games
High-Level Features
The main features of the Tic Tac Toe project are:
Game Board – Provides a 3×3 playing grid.
Two-Player Mode – Allows two players to play against each other.
Player Turns – Players take turns placing X and O.
Winner Detection – Automatically checks rows, columns, and diagonals.
Draw Detection – Detects when all positions are filled without a winner.
Input Validation – Prevents invalid or duplicate moves.
Restart Game – Allows players to start a new game.
