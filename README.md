# Tic-Tac-Toe-program
A Python- program Tic Tac Toe game featuring two-player gameplay, an interactive 3X3 board, input validation, win/draw detection, and simple game logic.
Overview of the project
Tic Tac Toe is a simple two player game developed by python.The game is played on a 3x3 grid where two player take turns marking their positions with X and O.The player who successful places three of their marks in horizontal, vertical or diagonal row wins the game.
Features
Two-player gameplay
3×3 game board
Player X and Player O
Turn-by-turn gameplay
Automatic winner detection
Draw/tie detection
Invalid input handling
Simple and user-friendly interface
Option to restart/play again
